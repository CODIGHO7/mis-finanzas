# Mis Finanzas

Aplicación web móvil para organizar ingresos, gastos, presupuestos, tarjetas y deudas, con un espacio separado para las finanzas del taller.

- Diseñada para teléfonos y Safari en iPhone.
- Los registros se guardan en el navegador, sin una base de datos externa.
- Incluye exportación e importación de copias de seguridad.
- No contiene datos personales precargados: cada usuario configura su espacio al iniciar.

## Abrir la aplicación

La página de inicio es `index.html`. Los archivos de interfaz, lógica, icono y manifiesto están en la raíz para poder servirlos directamente desde un hosting estático.
